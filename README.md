# Solana Live Screener — браузерная версия

Скринер работает прямо на странице Vercel: скачивать EXE, устанавливать Python и создавать `.env` не нужно. Пользователь вводит mint токена и один HTTPS RPC от Helius или QuickNode. Приложение извлекает из него ключ доступа и автоматически строит WSS endpoint, после чего вкладка браузера получает новые Solana-транзакции в live-режиме.

## Что сохранено

- стартовый slot фиксируется при нажатии «Запустить»; более старые события отбрасываются;
- пулы токена обнаруживаются через DexScreener и обновляются раз в минуту;
- подписки идут через Solana `logsSubscribe`;
- одна сложная транзакция может дать отдельные строки BUY и SELL;
- неуспешный DEX-вызов выводится как `FAILED SWAP` с нулевым исполнением;
- количество токена считается в raw units (`BigInt`) с учетом `decimals`;
- отображаются SOL сделки, SOL до/после, изменение SOL, комиссия, DEX, пользователь, slot и сокращенная signature;
- для HTTP 429 и временных RPC-ошибок действует exponential backoff;
- ошибки отдельных WebSocket-подписок показываются в интерфейсе.

## Быстрое развертывание на Vercel

Проект уже статический и не требует сборки.

1. Откройте PowerShell в этой папке:

   ```powershell
   cd "C:\Users\Admin\Documents\Codex\2026-08-15\new-chat\outputs\download-site"
   ```

2. Если Vercel CLI еще не установлен:

   ```powershell
   npm install -g vercel
   vercel login
   ```

3. Выполните production-развертывание:

   ```powershell
   vercel --prod
   ```

Папка уже связана с существующим Vercel-проектом через `.vercel/project.json`, поэтому дополнительных вопросов обычно не будет. В конце команда напечатает адрес production-сайта.

Если развертываете копию папки впервые, запустите сначала `vercel`, выберите `Create a new project`, подтвердите текущую папку и стандартные настройки. Затем выполните `vercel --prod`.

## Использование

1. Откройте сайт.
2. Вставьте mint токена.
3. Вставьте один HTTPS RPC: Helius вида `https://mainnet.helius-rpc.com/?api-key=...` или QuickNode вида `https://….solana-mainnet.quiknode.pro/<token>/`. WebSocket будет вычислен автоматически.
4. Нажмите «Запустить» и не закрывайте вкладку.

RPC-адрес не передается приложению на Vercel: запросы выполняются браузером напрямую к Helius или QuickNode. Флажок «Запомнить» сохраняет адрес в `localStorage` текущего браузера; на общем компьютере его лучше не включать.
